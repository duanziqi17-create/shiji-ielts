# 拾级英语 · IELTS 学习空间

一个面向大学英语四级约 400 分学习者的简洁 IELTS 学习网页。界面采用低饱和、三色以内的设计，支持从基础任务持续学习，而不是只显示七天计划。

## 主要功能

- 每日新词可选 10、20、30、50 个或自定 5–60 个；句子可选 3、5、10、15 句或自定 1–30 句。
- 达到每日额度后可立即进入下一关，也可以继续加练；加练时随时可以离开当前关卡。
- 清晰的单月学习日历，可切换月份，记录坚持天数、连续天数与每天完成内容。
- 完整纠错本，按 1、3、7、14、30 天间隔随机滚动复习。
- IELTS 写作与口语四项自检，参考官方评分维度。
- 分级英语阅读资源、阅读记录、学习词数和参考英语等级。
- 可切换原创起步词、四级、六级、考研、雅思、托福、GRE、SAT 词库，每本书分别保存学习位置。词库来自开源数据，许可及来源见 `VOCABULARY-LICENSES.md`。
- 内置查词，阅读时点词或划选词组查看本地提示；需要结合上下文时可打开有道词典、金山词霸或欧路词典。
- 「我的阅读」支持 PDF、EPUB、TXT、DOCX、HTML、Markdown、FB2，以及未加密的 MOBI/AZW3/AZW。书籍文件仅保存在当前浏览器。
- 所有进度保存在浏览器本地，可导出 JSON 备份并在其他设备导入。

## 使用方法

直接打开 `index.html` 即可使用。也可以把仓库部署到任意静态网站服务。

每个人的学习进度分别保存在自己的浏览器中。清理浏览器网站数据会删除本机进度，请定期使用网页里的“导出备份”。

备份包含阅读位置，不包含导入的电子书文件。换设备后需重新导入同名、同大小的原文件。扫描版 PDF 需要先进行 OCR；加密电子书、DjVu、KFX 等格式暂不支持。词组的本地释义是逐词提示，不是上下文翻译。
